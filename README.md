# AI Philosophy RSS

One paper per day, selected for a systematic reading program in philosophy of AI, language, mind, and science.

## Feeds

- `feed.xml`: daily paper recommendations.
- `test.xml`: two original embedded-text articles for KOReader compatibility testing.

## Static hosting

Use the `main` branch. Build command: `mkdir -p dist && cp feed.xml test.xml dist/`. Publish directory: `dist`. Enable automatic deployment on new commits. A domestic-accessible mirror is required for reliable use in mainland China.

## KOReader

Subscribe to the deployed site's `/test.xml` first. Disable Download Full Article and Download Images. Verify both test entries open as EPUB and contain their end markers. Then subscribe to `/feed.xml`.

Only embed complete papers when their redistribution is permitted by license or other authorization; otherwise publish bibliographic details, original summaries and legal full-text links. Do not redistribute unauthorized copies.
