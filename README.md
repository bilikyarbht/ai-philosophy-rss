# AI Philosophy RSS

One paper per day, selected for a systematic reading program in philosophy of AI, language, mind, and science.

## Subscribe

- Permanent KOReader subscription: https://bilikyarbht.github.io/ai-philosophy-rss/test.xml (retained to avoid reconfiguration).
- Identical alternative feed: https://bilikyarbht.github.io/ai-philosophy-rss/feed.xml.

GitHub Pages serves the main branch from the repository root. Both feed files must contain identical RSS content. Updates deploy automatically.

## KOReader

Keep Download Full Article and Download Images disabled. Synchronize news feeds; new books appear in the AI Philosophy - One Paper a Day folder.

RSS 2.0 must declare xmlns:content="http://purl.org/rss/1.0/modules/content/". Put all readable material in content:encoded as XML-escaped HTML (no CDATA). This format was confirmed on the Kindle in the V2 C test. Use unique article identifiers.

Only embed complete papers when their redistribution is permitted by license or other authorization; otherwise publish bibliographic details, original reading guides and legal full-text links. Mark such entries as reading guides. Do not redistribute unauthorized copies.
